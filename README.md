## `01` — Sobre mim

Olá! Sou **Matheus Silva**, estudante de **Tecnologia em Processos Gerenciais**, interessado na conexão entre gestão, tecnologia e dados.

Utilizo este espaço para organizar meus estudos, registrar minha evolução e desenvolver projetos relacionados às ferramentas que venho explorando.
